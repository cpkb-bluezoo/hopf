Cookbook: http-hello / http-get

Server

cargo run -p http-hello -- 127.0.0.1:8080
curl -v http://127.0.0.1:8080/
curl --http2-prior-knowledge http://127.0.0.1:8080/
cargo run -p http-hello -- --tls 127.0.0.1:8443
curl -vk https://127.0.0.1:8443/

Client

cargo run -p http-get -- http://127.0.0.1:8080/
# see example flags for --http2 / TLS

Sources: examples/http-hello, examples/http-get. Guides: HTTP overview.
