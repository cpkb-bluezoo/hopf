FTP

Crate `hopf-ftp`: FTP / FTPS **server** and blocking **client** (Gumdrop `org.bluezoo.gumdrop.ftp` port).

Crate hopf-ftp: FTP / FTPS server and blocking client (Gumdrop org.bluezoo.gumdrop.ftp port).

Server

FtpService + FtpConfig: control connection, PASV data listeners allocated on a shared Arc<Runtime>, stock FilesystemFtpHandler (chrooted root + storage API).

let policy = PasswordTrustPolicy::default().with_user("ftp", "ftp").shared();
let config = FtpConfig::new(addr, root, policy);
// optional: .with_tls(acceptor).implicit_ftps().require_data_tls()
let service = FtpService::new(config);
let rt = Arc::new(Runtime::start(RuntimeConfig::default())?);
let bound = service.start(Arc::clone(&rt))?;

Custom apps implement FtpConnectionHandler (authenticate, file_system, is_authorized) via FtpService::with_handler_factory.

Config highlights: TrustPolicy, TLS acceptor, implicit_tls, require_tls_for_data, PASV advertised IP / port range, read_only, allow_active_bounce. Explicit FTPS: with_starttls_acceptor; implicit FTPS: with_tls on the listener.

RFC 2640 OPTS UTF8 ON for pathnames and listings (ASCII substitution when UTF-8 is off).

Client

FtpClient / FtpClientBuilder: USER/PASS, TYPE, path ops, PASV/EPSV (optional PORT/EPRT), RETR/STOR/LIST, explicit AUTH TLS, implicit FTPS + PROT P. Builder: .tls(ClientConfig, name), .implicit_tls(true), .data_mode, .prefer_epsv, timeout.
