Crate `hopf-dns`: **stub resolver + caching forwarder** (not authoritative).

Crate hopf-dns: stub resolver + caching forwarder (not authoritative).

Resolver

Reactor-affine UDP (and optional TCP / DoT / DoQ / DoH) on worker reactors via core UDP APIs. Shared cache, hosts file, system resolvers, EDNS/cookies/bailiwick. Feature dnssec enables validation with ring.

Dial helpers: RuntimeDnsExt::connect_by_name when you need name → A/AAAA then TCP connect on the owning reactor.

Server / proxy

DnsService + UDP listener; optional DoT/DoQ features. Demo: examples/dns-proxy — see dns-proxy.

Non-goals (same as Gumdrop): authoritative zones, AXFR, TSIG, UPDATE, DNSSEC signing, DoH server.
