Runtime options

RuntimeConfig

Field Meaning
worker_threads Reactor count. 0 → available_parallelism * 2 (min 2)
storage StorageConfig for the blocking pool 
let rt = Runtime::start(RuntimeConfig {
    worker_threads: 4,
    ..Default::default()
})?;

With telemetry: Runtime::start_with_telemetry(config, Some(hook)) or Composition::telemetry(hook).

Per-connection knobs (TcpListenerConfig / connector)

Typical fields (see crate docs): buffer sizes, max net in/out, idle timers, optional TLS acceptor/connector, STARTTLS acceptor, ACL, rate limit.

Storage and execute

  • rt.storage().submit(…) — blocking work off-loop
  • Hop results to the connection via ConnHandle / Endpoint::execute so the reactor stays non-blocking

Worker handles

rt.worker(i) / rt.pick_worker() — for UDP registration, DNS, and advanced reactor-affine work.
