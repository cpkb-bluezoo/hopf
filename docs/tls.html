PEM accept / dial

use hopf_tls::acceptor_from_pem;
// TcpListenerConfig::new(...).with_tls(acceptor)

Client side: connector from PEM / WebPKI roots as appropriate; attach with TcpConnectorConfig::with_tls.

ALPN

Pass protocol list when building the acceptor (e.g. &[b"h2", b"http/1.1"]). HTTP demos use AlpnHttpEndpoint to select H2 vs H1 after handshake.

STARTTLS

Cleartext first, then upgrade: TcpListenerConfig::with_starttls_acceptor and Endpoint::start_tls from the protocol handler when the application grammar says so (mail-style). Prefer from-accept TLS when the binding is always secure.
