WebDAV

Crate `hopf-webdav`: **RFC 4918** filesystem WebDAV for Hopf HTTP servers (tractrix for wire XML).

Crate hopf-webdav: RFC 4918 filesystem WebDAV for Hopf HTTP servers (tractrix for wire XML).

Scope

When webdav_enabled is set, the handler serves PROPFIND, PROPPATCH, LOCK, UNLOCK, MKCOL, COPY, MOVE, plus GET/HEAD/OPTIONS (and PUT/DELETE when allow_write). Without the WebDAV flag it stays a plain file server (OPTIONS/GET/HEAD ± write).

Dead properties: DeadPropMode::Auto / Xattr / Sidecar / None (sidecar prefix .webdav_, Gumdrop-compatible). Locks are in-process per factory.

Filesystem work runs on StorageExecutor — never on a reactor thread.

Wiring

let storage = Arc::new(StorageExecutor::new(StorageConfig::default()));
let config = WebDavConfig {
    root_path,
    allow_write: true,
    webdav_enabled: true,
    welcome_file: "index.html".into(),
    dead_property_storage: DeadPropMode::Auto,
};
let factory: Arc<dyn ServerHandlerFactory> =
    Arc::new(WebDavFactory::new(config, storage)?);
rt.add_tcp_listener(TcpListenerConfig::new(addr, move || {
    Box::new(CleartextHttpEndpoint::new(
        Arc::clone(&factory),
        HttpLimits::default(),
    ))
}))?;

TLS uses the usual HTTP TLS endpoints (AlpnHttpEndpoint / H1 over rustls). Stock handler has no TrustPolicy gate.
