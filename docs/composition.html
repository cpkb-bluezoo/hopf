Composition

Canonical Rust script surface (issue #8). XML via tractrix desugars into the same builder.

Builder

use hopf_core::{Composition, RuntimeConfig, TcpListenerConfig, TcpConnectorConfig};

let comp = Composition::new(RuntimeConfig::default())
    .telemetry(hook)                 // optional Arc<dyn TelemetryHook>
    .listen_tcp(listen_cfg)
    .dial_tcp(dial_cfg)              // applied after listens
    .build()?;

let addr = comp.primary_addr();
let id = comp.bindings[0];
comp.remove_binding(id);
comp.shutdown();

build starts the Runtime (with optional telemetry), registers queued listens (recording BindingIds and local addresses), then dials.

XML (tractrix)

Declarative files use elements and attributes only (no character data). Naming mirrors the builder. Parsing is entirely through tractrix.

<composition worker-threads="4" storage-threads="4">
  <listen-tcp addr="127.0.0.1:0" handler="echo"
              max-net-in="1048576" max-net-out="4194304"
              idle-timeout-ms="60000">
    <allow cidr="10.0.0.0/8"/>
    <deny cidr="192.0.2.0/24"/>
    <rate-limit per-source="100" window-ms="1000" global="0"/>
  </listen-tcp>
  <dial-tcp addr="127.0.0.1:8080" handler="echo"/>
</composition>

handler="…" is not a Service or HTTP Stream handler name. It resolves a closed registry of connection-level HandlerFactory values (Fn() -> Box<dyn ProtocolHandler>). Register pre-wired stacks in Rust before load — no reflective DI.

use std::sync::Arc;
use hopf_core::{Composition, CompositionRegistry, ProtocolHandler};

let mut reg = CompositionRegistry::new();
reg.register("echo", Arc::new(|| Box::new(Echo) as Box<dyn ProtocolHandler>));
// HTTP: register CleartextHttpEndpoint / AlpnHttpEndpoint under a short name.

let comp = Composition::from_xml_str(xml, &reg)?
    .telemetry(hook)   // optional; not expressed in XML v1
    .build()?;

Also: Composition::from_xml, from_xml_path. TLS / secure attributes are rejected in v1 (wire TLS in the registered factory or Rust builder).

Binding lifecycle

  • Add — Composition::listen_tcp or Runtime::add_tcp_listener → (SocketAddr, BindingId)
  • Remove — CompositionRuntime::remove_binding / Runtime::remove_binding
  • Accept loop deregisters the mio listener; existing connections keep affinity until close

Trust policies and DNS caches attach at the protocol layer (e.g. HTTP BasicAuthFactory, DnsResolver), not as core Composition fields — core stays free of HTTP/auth types.
