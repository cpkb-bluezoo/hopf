WebSocket

Crate `hopf-websocket`: **RFC 6455** framing with push-incremental parse and app event handlers.

Crate hopf-websocket: RFC 6455 framing with push-incremental parse and app event handlers.

Bootstraps

Handshake rides Hopf HTTP upgrade seams:

  • HTTP/1.1 Upgrade
  • HTTP/2 Extended CONNECT (RFC 8441)
  • HTTP/3 Extended CONNECT (RFC 9220)

Implement WsEventHandlerFactory::create(path, headers) → Box<dyn WsEventHandler> (on_open, text/binary, ping/pong, close). Send with WsSession::send_text / send_binary / send_ping / send_close.

Text/binary callbacks currently assume single-frame messages (no reassembly yet).

Wiring

let factory = Arc::new(WebSocketFactory::new(
    EchoFactory, // or your WsEventHandlerFactory
    WebSocketConfig::default(),
));
rt.add_tcp_listener(TcpListenerConfig::new(addr, move || {
    Box::new(CleartextHttpEndpoint::new(
        Arc::clone(&factory) as Arc<dyn ServerHandlerFactory>,
        HttpLimits::default(),
    ))
}))?;

WebSocketConfig: max_payload (default 16 MiB), optional subprotocol.
