SMTP

Crate `hopf-smtp`: SMTP / SMTPS **server** and blocking **client** (Gumdrop `org.bluezoo.gumdrop.smtp` port).

Crate hopf-smtp: SMTP / SMTPS server and blocking client (Gumdrop org.bluezoo.gumdrop.smtp port).

Server

Staged connection SPI: SmtpClientConnected → HelloHandler → MailFromHandler → RecipientHandler → MessageDataHandler. DATA (dot-stuffing) and BDAT (CHUNKING). EHLO advertisements include SIZE, PIPELINING, 8BITMIME, SMTPUTF8, CHUNKING, optional STARTTLS and AUTH PLAIN.

Stock AcceptAllSmtpHandler accepts every stage and discards the message (greeting {hostname} ESMTP Hopf). Wire with SmtpService::new(SmtpConfig::new(addr, hostname)).

let config = SmtpConfig::new(addr, "localhost");
// .with_tls(a).implicit_tls().auth_required(true).with_policy(policy)
let service = SmtpService::new(config);
let bound = service.start(Arc::new(Runtime::start(RuntimeConfig::default())?))?;

Defaults: max message 35 MiB, max recipients 100. STARTTLS via with_starttls_acceptor; SMTPS via with_tls + implicit_tls.

Local mailbox delivery is not built in yet — implement a custom MessageDataHandler that appends via hopf-mailbox on the storage pool.

Simple relay

SimpleRelayService / SimpleRelayHandler — open MX relay for any sender/recipient. Buffers the message, groups RCPT by domain, looks up MX with hopf-dns, and delivers with blocking SmtpClient on a worker thread.

Dev / test / closed networks only — not for untrusted ingress.

let rt = Arc::new(Runtime::start(RuntimeConfig::default())?);
let relay = SimpleRelayService::new(
    SmtpConfig::new(addr, hostname),
    Arc::clone(&rt),
)?;
relay.start(Arc::clone(&rt))?;

Defaults: DNS timeout 5s, outbound port 25, SMTP I/O timeout 60s. Tests can inject a resolver with with_resolver. FUTURERELEASE is rejected; REQUIRETLS currently fails delivery (no trust roots for arbitrary MX STARTTLS). There is no examples/smtp-relay binary yet — see hopf-smtp integration tests (simple_relay_mx_to_local_sink).

Client

SmtpClient / SmtpClientBuilder: EHLO/HELO, MAIL/RCPT, DATA, BDAT, STARTTLS, AUTH PLAIN, QUIT. TLS: .tls(cfg, name).implicit_tls(true) or .starttls().
