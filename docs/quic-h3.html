Crate hopf-quic wraps quinn-proto with mio/TPC glue (not the full quinn crate). HTTP/3 lives in hopf-http behind feature h3.

Listen / dial QUIC

RuntimeQuicExt::{add_quic_listener, connect_quic} (and hook variants). TLS 1.3 identity comes from hopf-tls helpers shared with TCP TLS.

H3

cargo run -p http3-hello -- …
# curl --http3-only …

Each H3 request maps to a QUIC-stream Endpoint driving the same ServerHandler app API as H1/H2.

Deferred: server push, datagrams, WebTransport, full 0-RTT polish.
