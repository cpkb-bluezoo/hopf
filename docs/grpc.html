gRPC

Crate `hopf-grpc`: **unary** gRPC over Hopf HTTP Streams — Gumdrop `org.bluezoo.gumdrop.grpc` architecture.

Crate hopf-grpc: unary gRPC over Hopf HTTP Streams — Gumdrop org.bluezoo.gumdrop.grpc architecture.

Model

  • Length-prefixed frames; content-type application/grpc
  • Runtime .proto via ProtoFileParser / ProtoFile (no generated stubs, no message DOM at the app boundary)
  • Schema-aware push decode/encode through rprotobuf
  • Unimplemented methods → gRPC status 12
  • Default max message size 4 MiB (set_max_message_size)

Server wiring

let proto = ProtoFileParser::parse(PROTO)?;
let factory = Arc::new(GrpcHandlerFactory::new(proto, Arc::new(EchoService)));
rt.add_tcp_listener(TcpListenerConfig::new(addr, move || {
    Box::new(CleartextHttpEndpoint::new(
        Arc::clone(&factory) as Arc<dyn ServerHandlerFactory>,
        HttpLimits::default(),
    ))
}))?;

impl GrpcService for EchoService {
    fn start_unary_call(
        &self,
        path: &str,
        response: GrpcResponseChannel,
    ) -> Option<Box<dyn ProtoMessageHandler>> {
        // match "/pkg.Service/Method", return a ProtoMessageHandler
        // that fills the reply via response.open_message / complete
        None
    }
}

Client

GrpcClient::unary_call(path, unframed_request_bytes, handler) produces a ClientHandlerFactory for Hopf HTTP dial.
