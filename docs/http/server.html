HTTP server

ServerHandler

impl ServerHandler for Hello {
    fn headers(&mut self, response: &mut dyn ServerWriter, headers: &Headers) {
        // may write a full response here
    }
    fn request_complete(&mut self, response: &mut dyn ServerWriter) {}
}

Body sequence when present: headers → start_request_body → request_body_content* → end_request_body → request_complete.

ServerWriter

Buffer status/headers, then start_response_body / response_body_content / end_response_body / complete. Informational 1xx via send_informational.

Limits

HttpLimits caps header sizes, body sizes, etc. Pass into endpoint constructors.

Authentication

Wrap the handler factory with BasicAuthFactory, DigestAuthFactory, or BearerAuthFactory. Digest needs a CredentialStore (e.g. PasswordStore) for HA1. See Auth.

use hopf_http::{BasicAuthFactory, BasicAuthConfig, DigestAuthFactory, DigestAuthConfig};
use hopf_auth::{PasswordTrustPolicy, PasswordStore};
use std::sync::Arc;

let basic = Arc::new(BasicAuthFactory::new(
    inner_factory.clone(),
    PasswordTrustPolicy::new().with_user("alice", "s3cret").shared(),
    BasicAuthConfig::new("realm"),
));
let digest = Arc::new(DigestAuthFactory::new(
    inner_factory,
    Arc::new(PasswordStore::new().with_user("alice", "s3cret")),
    DigestAuthConfig::new("realm"),
));
