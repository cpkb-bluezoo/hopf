Demo: examples/http-get.

Patterns:

  • H1 — H1Endpoint::client + ClientHandler / ClientWriter
  • H2 — H2Endpoint::client (preface + SETTINGS); http-get --http2
  • H3 — connect_h3 with feature h3

Implement ClientHandler for response events (headers, body chunks, complete). Dial with Runtime::connect and a TLS connector when using HTTPS.
